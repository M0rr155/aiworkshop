# AI Workshop - OpenEdge ABL Project

This repository contains an OpenEdge ABL project used for the AI Workshop.

## Project Structure

- `src/` - ABL source files (classes, windows, procedures)
- `src/business/` - Business entity layer (EntityFactory, CustomerEntity)
- `dump/` - Database schema files
- `doc/` - Documentation
- `.windsurf/` - Windsurf AI rules and workflows

## Getting Started

1. Ensure OpenEdge is installed and `DLC` environment variable is set
2. Configure a Sports2000 database connection
3. Open the project in Progress Developer Studio or VS Code with ABL extension
