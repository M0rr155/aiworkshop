# Add a New Method

This workflow adds a new method to the currently focused ABL class.

1. **Method Name** - PascalCase
2. **Return Type** - VOID, CHARACTER, INTEGER, DECIMAL, LOGICAL, etc.
3. **Access Modifier** - PUBLIC, PROTECTED, PRIVATE
4. **Parameters** - format: `paramName AS dataType`
5. **Method Body** - implementation code

## Best Practices

- Use named buffers for database access
- Document all parameters and return values
- Keep methods focused on a single responsibility
